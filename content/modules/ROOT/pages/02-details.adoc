== Technical requirements

=== Tools used

* **GitHub CLI** (`gh`) -- create repositories from templates
* **Git** -- version control
* **Podman** -- local preview of Showroom content
* **Claude Code** -- AI-assisted content generation with RHDP skills

=== Environment access

All tools are pre-installed in the lab environment. You will use the Terminal tab on the right side of this screen for all commands.

You also need:

* A GitHub account with write access to the link:https://github.com/rhpds[rhpds organization^]
* The RHDP Skills Marketplace plugin installed in Claude Code

== Troubleshooting

**Problem**: `gh: command not found`

**Solution**: The GitHub CLI should be pre-installed. If not, follow the installation instructions at link:https://cli.github.com[cli.github.com^].

**Problem**: GitHub Pages shows a 404 after pushing

**Solution**: GitHub Pages deployments take 1-2 minutes. Check the Actions tab in your repository to monitor the build status.

**Problem**: Podman preview shows a blank page

**Solution**: Ensure you are running the command from the repository root directory where `site.yml` is located.
