= Getting started with Red Hat Showroom

A 30-45 minute hands-on workshop that teaches Red Hat associates how to create their own Showroom workshops and demos. Learners use Claude Code and the RHDP Skills Marketplace to generate production-quality content, configure a Showroom repository, and publish to GitHub Pages -- all from their local laptop.

This is the only showroom that teaches showroom creation: a "meta-showroom" where the output of the lab is itself a working showroom.

**Rendered workshop**: https://rhpds.github.io/showroom-getting-started-showroom

== Local development

Clone and preview locally:

[source,sh]
----
git clone https://github.com/rhpds/showroom-getting-started-showroom.git
cd showroom-getting-started-showroom
podman run --rm --name antora -v $PWD:/antora -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

On SELinux systems (RHEL, Fedora), append `:z` to the volume mount: `-v $PWD:/antora:z`.

Then open http://localhost:8080 in your browser.
